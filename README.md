## ⚙️ Requirements

- **Python** 3.8+
- **Jupyter Notebook** or **JupyterLab**
- Common Python libraries:
  - `numpy`, `pandas`, `matplotlib`, `seaborn`
  - `scikit-learn` (Machine Learning notebooks)
  - `tensorflow` / `keras` or `torch` (Deep Learning notebooks)

Install core dependencies:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/abdurrahmanse/phitron-projects.git
cd phitron-projects

# 2. Launch Jupyter
jupyter notebook
```

Then navigate to any course folder and open a `.ipynb` file.

> **Note:** Keep the `data/` folders in their original locations — notebooks reference them using relative paths.
